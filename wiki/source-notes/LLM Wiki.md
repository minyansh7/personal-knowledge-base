# Overview

Idea file describing LLM Wiki pattern for personal knowledge bases, emphasizing persistent wiki maintenance by LLMs over RAG-style retrieval.

# Key Insights

- **Core Difference**: Wiki compounds knowledge incrementally vs. rediscovering on each query.
- **Architecture**: Raw sources, wiki pages, schema configuration.
- **Operations**: Ingest, query, lint with LLM handling maintenance.
- **Tools**: Obsidian for IDE, qmd for search, git for versioning.
- **Applications**: Personal tracking, research, business wikis.

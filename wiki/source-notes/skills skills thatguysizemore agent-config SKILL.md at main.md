# skills/skills/thatguysizemore/agent-config/SKILL.md at main

## Overview
OpenClaw skill for intelligently modifying agent core context files like AGENTS.md, SOUL.md, etc., with workflows for file identification, state checking, and change drafting.

## Key Insights
- Workflow: Identify target file based on content type; check size limits and duplication; draft changes following format guidelines.
- File purposes: AGENTS.md for operations/procedures; SOUL.md for personality/tone; IDENTITY.md for core vibe; USER.md for profile; TOOLS.md for local tools; MEMORY.md for facts; HEARTBEAT.md for checklists.
- Formats: Structured imperative for AGENTS.md; narrative for SOUL.md; minimal for IDENTITY.md; factual bullets for USER.md.
- Best practices: Respect 20K char limits, avoid duplication, ensure subagent visibility.
